Módulos principales

Gestión de bodegas

Registra, consulta, actualiza y elimina las bodegas administradas por LogiTrack.

Cada bodega puede almacenar su nombre, ubicación, capacidad y usuario encargado.

Ir a bodegas

Gestión de productos

Administra los datos generales de los productos disponibles en el sistema.

El stock se controla por cada bodega mediante los registros de inventario.

Ir a productos

Movimientos de inventario

Registra entradas, salidas y transferencias de productos entre las bodegas.

Cada movimiento conserva la fecha, el usuario responsable, las bodegas involucradas y las cantidades.

Ir a movimientos

Seguridad y trazabilidad

Las solicitudes protegidas del sistema deben enviar el token JWT obtenido durante el inicio de sesión.

Las operaciones realizadas por los usuarios pueden registrarse mediante el módulo de auditoría para conservar la trazabilidad de los cambios.
